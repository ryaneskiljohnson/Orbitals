# Zenith - MIDI Velocity Expander

**Zenith** is a MIDI velocity processor that expands dynamic range by amplifying velocity values towards their maximum, creating more expressive and dynamic performances.

## Concept

Named after the highest point in the sky directly above an observer, Zenith represents the peak, the apex, the culmination. It takes incoming MIDI notes and expands their velocity towards maximum values, creating brighter, more expressive performances.

## Theme

- **Color**: Sky Blue / Bright Cyan (`#f0f9ff`, `#38bdf8`, `#0ea5e9`)
- **Visual Style**: Clean, bright, minimal - representing reaching the highest point
- **Aspect Ratio**: 16:10 (1200x750)

## Parameters

- **Expansion**: Amount of velocity expansion (0-100%)
- **Threshold**: Velocity threshold above which expansion is applied
- **Ceiling**: Maximum velocity limit
- **Curve**: Shape of the expansion curve (linear to exponential)

## Plugin Formats

- VST3
- AU (AudioUnit)
- Standalone Application
