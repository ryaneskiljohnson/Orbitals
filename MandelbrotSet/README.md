## 🚀 Quick Start

### Installation

```bash
# VST3
cp -R [Plugin]_artefacts/VST3/[Plugin].vst3 ~/Library/Audio/Plug-Ins/VST3/

# AU
cp -R [Plugin]_artefacts/AU/[Plugin].component ~/Library/Audio/Plug-Ins/Components/
```

### Using

1. Open your DAW (Logic, Ableton, Reaper, etc.)
2. Rescan plugins
3. Insert Mandelbrot Set plugin as Audio FX
4. Beautiful quantum-themed UI opens automatically!
