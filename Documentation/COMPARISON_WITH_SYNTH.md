# 🔍 Comparison: Perihelion vs Synth (Working)

## Key Differences

### 1. **Project Type**
- **Synth**: `guiapp` (standalone application)
- **Perihelion**: `audioplug` (plugin with standalone export)

### 2. **Modules in .jucer**
**Synth has:**
- ✅ `juce_audio_utils` 
- ✅ `juce_audio_devices`
- ✅ `juce_audio_formats`
- ✅ `juce_dsp`

**Perihelion now has (after fixes):**
- ✅ `juce_audio_utils` (added)
- ✅ `juce_audio_devices` (added)
- ❌ `juce_audio_formats` (missing, but not needed for MIDI FX)
- ❌ `juce_dsp` (missing, but not needed)

### 3. **Standalone Wrapper**
- **Synth**:** Has `Main.cpp` with `START_JUCE_APPLICATION` - works as standalone app
- **Perihelion**: Needs `juce_audio_plugin_client_Standalone.cpp` wrapper - **Projucer should generate this but doesn't**

### 4. **Header Search Paths**
**Synth includes:**
- `JUCE/modules` (via module paths)

**Perihelion needs:**
- `../../Synth/JUCE/modules` in header search paths for standalone wrapper to find `juce_audio_plugin_client` headers

### 5. **JuceLibraryCode Files**
**Synth has:**
- `include_juce_audio_utils.cpp/mm` ✅
- All module files properly generated

**Perihelion has:**
- `include_juce_audio_utils.cpp/mm` ✅ (after regeneration)
- Missing standalone wrapper file (needs to be generated by Projucer)

## The Real Problem

**Projucer is NOT generating the standalone wrapper code** when you export to Xcode. It should create:
- A standalone wrapper file in `JuceLibraryCode/`
- Proper file references in the Xcode project
- Correct header search paths

## Solution

**You MUST regenerate in Projucer** - the Xcode project I tried to fix manually is now corrupted. 

1. **Close Xcode**
2. **Open `Perihelion.jucer` in Projucer**
3. **Verify modules are correct** (should have `juce_audio_utils` and `juce_audio_devices`)
4. **Click "Save and Open in IDE"**
5. **Projucer will regenerate the project correctly**

The .jucer file is now correctly configured with all needed modules. Projucer just needs to regenerate the Xcode project to create the standalone wrapper properly.
