## 🔨 How to Build

### Required Software
- **Projucer** (from JUCE framework)
- **Xcode** (macOS) or **Visual Studio** (Windows)
- **JUCE 8+** (already in each plugin folder)

### Build Process

```bash
# 1. Open Projucer and load a .jucer file:
open /Users/rjmacbookpro/Development/Orbitals/Tidal/Tidal.jucer

# 2. In Projucer, click "Save and Open in IDE"
# 3. Xcode opens automatically
# 4. Select scheme: "Tidal - VST3" or "Tidal - AU"
# 5. Press ⌘B to build
# 6. Find plugin in: Builds/MacOSX/build/Release/
```

Repeat for all 8 plugins.
