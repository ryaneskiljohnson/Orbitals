## 🚀 How to Use

### Test Fabric Now
```bash
./MandelbrotSet/Fabric/launch_fabric.sh
```

Or:
```bash
open MandelbrotSet/Fabric/Builds/MacOSX/build/Debug/Fabric.app
```

1. Allow microphone when prompted
2. Click ⚙️ → Select "Built-in Microphone"
3. Speak → Hear reverb!
4. Move controls → Instant response!

### Build Any Plugin
```bash
cd [Plugin]/Builds/MacOSX
xcodebuild -project [Plugin].xcodeproj -scheme "[Plugin] - All" -configuration Debug build
```

### Build All Plugins
```bash
./build_and_verify_all.sh
```
