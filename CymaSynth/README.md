# CymaSynth

**CymaSynth** is a visual plugin experience.

## Concept

CymaSynth provides a clean, minimal visual interface.

## Theme

- **Color**: Sky Blue / Bright Cyan (`#f0f9ff`, `#38bdf8`, `#0ea5e9`)
- **Visual Style**: Clean, bright, minimal
- **Aspect Ratio**: 16:10 (1200x750)

## Plugin Formats

- VST3
- AU (AudioUnit)
- Standalone Application
