# Zenith UI Controls

## Parameters

1. **Expansion** (0-100%) - Amount of velocity expansion applied
2. **Threshold** (0-127) - Velocity threshold above which expansion is applied
3. **Ceiling** (0-127) - Maximum velocity limit
4. **Curve** (0-100%) - Shape of the expansion curve (linear to exponential)

## UI Layout

- Vertical sliders for Expansion and Curve
- Horizontal sliders for Threshold and Ceiling
- Or adapt Lagrange's layout as needed
