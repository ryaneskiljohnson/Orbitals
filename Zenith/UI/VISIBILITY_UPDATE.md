# Zenith UI - Visibility Improvements

## Changes Made
Added semi-transparent background masks to improve visibility:

### 1. Control Labels
- Background: `rgba(0, 0, 0, 0.6)` with blur
- Border: Subtle cyan border
- Padding: Comfortable spacing
- Backdrop filter: 8px blur

### 2. Value Displays
- Background: `rgba(0, 0, 0, 0.5)` with blur
- Border: Lighter cyan border
- Backdrop filter: 6px blur
- Larger padding for readability

### 3. Slider Tracks
- Background: `rgba(0, 0, 0, 0.4)` with blur
- Enhanced border visibility
- Inner shadow for depth
- Backdrop filter: 4px blur

### 4. Knob
- Layered background with dark base
- Backdrop filter: 8px blur
- Enhanced border and shadows
- Better contrast against background

All elements now have better visibility while maintaining the clean sky-blue Zenith aesthetic!
